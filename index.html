Arquitetura Serverless P2P

Sem servidores próprios. O Host gerencia a sala via PeerJS. Se um jogador cair, um robô assume automaticamente e devolve o controle assim que o jogador reconectar.

📋 Recursos Implementados

  • ✓ Conta Local: Perfil salvo no localStorage sem autenticação externa.
  • ✓ Salas P2P de até 6 pessoas: Lobbies dinâmicos via WebRTC.
  • ✓ Failover com Robô: Queda de conexão ativa bot no Host sem travar o jogo.
  • ✓ Reconexão Transparente: Reassume a vaga e recebe snapshot do estado.
  • ✓ Stickers em Tempo Real: Reações animadas flutuantes entre os jogadores.
  • ✓ Memes de Derrota: Carimbos e sons cômicos aleatórios para quem perder o monte.
